Privacy policy

Hermes Google Drive · Last updated September 29, 2026

This policy describes the private, owner-operated Hermes Google Drive integration and these public information pages. The local installation is administered by the same person who authorizes its Google account.

Data accessed and purpose

With the owner's consent, the integration uses Google's Drive and Docs APIs to find, read, create, edit, organize, trash, restore or explicitly permanently delete files needed for authorized tasks. Access includes file names, identifiers, types, descriptions, folder relationships, versions and timestamps, plus selected supported file or document contents. The account email address is checked and retained to confirm that the connection uses the account authorized during setup; Google account display information may be returned during that check.

The requested https://www.googleapis.com/auth/drive permission is broad Drive access, not a permission limited to selected folders. Task instructions limit ordinary retrieval and actions to relevant material. The helper does not automatically mirror all of Drive, change sharing permissions or request Gmail, Calendar or Contacts scopes.

AI processing and other transfers

Selected Drive content and metadata may be provided to the assistant and its delegated agents to answer questions, reason about a task, create outputs or verify changes. The configured model service, currently OpenAI in this installation, may receive these excerpts and related prompts. Its processing and retention depend on the applicable account terms and data controls; this integration does not promise local-only processing or zero retention by external services.

Google receives API requests and data written back to Drive. Task records, selected source material, outputs and learned context may be retained in the owner's private workspace and included in owner-configured private backups, including private GitHub storage. This does not make those records public. No automatic public publication is part of the Drive helper.

The integration uses Google data to carry out the owner's requested or authorized assistant features. It does not sell Google data or use it for advertising, data brokerage or credit scoring. It does not itself train or fine-tune models. The owner must select model-service settings and terms appropriate for this data; this page does not assert that an external provider's account controls have been independently audited.

Authorization and credential storage

Authorization uses Google's browser-based OAuth flow with a local callback. The helper does not copy browser cookies or request the Google account password. OAuth client information, an access token, a refresh token and the authorized account identifier are saved in private local runtime files so access can be renewed without signing in for each task. These credentials are intended to remain outside knowledge bases, source repositories and backup manifests.

The helper uses HTTPS for Google API requests and avoids logging credential and OAuth response bodies. Local filesystem protections are part of the installation. These measures do not constitute a guarantee against every disclosure or security incident.

Retention and removal

There is no automatic expiration period for all retained task records or knowledge. The owner manages local files, assistant history, organizational memory and backup retention. Selected content or derived notes can remain in those places until removed, including older private backup copies. AI-provider and Google retention is governed separately by those services and the account's settings.

The owner can stop future authorized access by removing this application's connection in Google Account third-party connections and removing the local integration's saved OAuth credentials. Revoking access does not erase previously retrieved content, generated outputs, task history or backups. To remove those copies, the owner must also delete the relevant local records and address any retained copies with the applicable storage or model provider. Drive files can be managed directly in Google Drive; Trash and permanent deletion have different consequences.

These public pages

These pages have no forms, JavaScript, embedded media, analytics or advertising added by this integration. They do not receive Drive content or OAuth credentials. When served by GitHub Pages, GitHub processes visitor information such as IP addresses for hosting and security under its privacy statement. Following a link to another service is subject to that service's own practices.

Administration and policy changes

For this single-owner installation, the account owner handles privacy questions, access changes and data removal through their local workspace and Google Account controls. The app is not available for public account registration. If the integration's data use changes, this policy and the owner's disclosures must be updated before the new use begins, with additional consent where required.

Google API data handling is subject to the Google API Services User Data Policy, including its Limited Use requirements. This policy describes the integration's operation; it is not a claim of Google verification, endorsement or a security audit.
