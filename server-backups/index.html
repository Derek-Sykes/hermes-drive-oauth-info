Derek Server Backups

A private utility operated by Derek Sykes for encrypted backups and authorized file access in his own Google Drive. It uses rclone on his server and is not offered as a public service.

Drive access supports listing files, uploading encrypted backup archives, downloading and verifying backups, and moving proven superseded snapshots to Drive trash after verification.

This information site contains no backup contents or credentials.
