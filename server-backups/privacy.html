Privacy Policy

Effective November 15, 2026.

Derek Server Backups is a personal utility operated by Derek Sykes. Access is authorized by the Google account owner and used for backups and requested file operations in that account.

Google Drive access

The utility requests Drive access to list and read files, create and download encrypted backups, verify backup integrity, and move verified superseded backup files to Drive trash. Broad Drive scope is needed to access existing files and backups created under earlier clients.

Data handling and retention

Processing takes place on the owner's server. Backup archives are encrypted before upload. Temporary backup transfer and restore payloads are removed after verification; operational receipts are retained locally. Original files and other retained source data follow the owner's instructions.

Google user data is not sold, used for advertising, or used to train generalized artificial intelligence models. It is used only to carry out the owner's authorized operations. The public information site does not receive Drive contents or OAuth credentials.

Control

The owner can revoke access through Google Account permissions. Revoking access does not itself remove files already stored in Drive.

Derek Server Backups' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
